# ***Linux Basics for Hackers - Chapter 1 Notes***

## Key Terms & Concepts

### Binaries

- Executable files (like .exe in Windows)
- Located in `/usr/bin` or `/usr/sbin`
- Examples: `ps`, `cat`, `ls`, `ifconfig`
- Includes tools like `aircrack-ng` and `Snort IDS`

### Case Sensitivity

- **Linux is case-sensitive** (unlike Windows)
- `Desktop` ≠ `desktop` ≠ `DeskTop`
- Common error: "file or directory not found" often means case mismatch

### Directory

- Same as Windows "folder"
- Hierarchical organization of files

### Home Directory

- Each user has `/home` directory
- Default save location for user files

### Kali Linux

- Distribution designed for penetration testing
- Hundreds of pre-installed tools
- Book uses Kali 2018.2 (April 2018)

### Root Account

- Administrator/superuser account
- Can do nearly anything on the system
- Used for system configuration, adding users, changing passwords
- **Many hacking tools require root access**

### Script

- Series of commands in interpretive environment
- Common interpreters: Bash, Python, Perl, Ruby
- **Python is most popular among hackers**

### Shell

- Environment for running commands
- **Bash** (Bourne-again shell) - most widely used
- Others: C shell, Z shell

### Terminal

- Command line interface (CLI)

---

## Linux Filesystem Structure

### Root Directory: `/`

The top of the filesystem tree (inverted tree structure)

### Important Directories

| Directory | Purpose |
| --- | --- |
| `/root` | Home directory of root user |
| `/etc` | System configuration files |
| `/home` | User home directories |
| `/mnt` | Mount point for filesystems |
| `/media` | Mount point for CDs/USB devices |
| `/bin` | Application binaries/executables |
| `/lib` | Shared libraries (like Windows DLLs) |
| `/boot` | Kernel image |
| `/dev` | Special device files |
| `/sys` | Kernel's hardware view |
| `/proc` | Internal kernel data view |
| `/usr` | Additional binaries, libraries |

---

## Important Security Notes

⚠️ **Do NOT log in as root for routine tasks**

- Reason: If hacked while logged in as root, attacker gains full system control
- Use regular user account for:
    - Browsing the web
    - Running Wireshark
    - Other routine applications
- Only use root for administrative tasks and when specifically required

# ***Linux Basic Commands - Study Notes***

## Navigation Commands

### pwd (Present Working Directory)

- Shows your current location in the directory structure
- Example: `pwd` → returns `/root`
- Useful when working in command line where current directory isn't always visible

### whoami

- Displays which user you're currently logged in as
- Important for checking if you have root (superuser) privileges
- Root user has all system privileges (add users, change passwords, etc.)
- Example: `whoami` → returns `root` or your username

### cd (Change Directory)

- Navigate between directories
- `cd /etc` - go to specific directory
- `cd ..` - move up one level
- `cd ../..` - move up two levels
- `cd ../../..` - move up three levels
- `cd -` - change to previous directory
- `cd /` - go to root directory from anywhere
- **`pushd <dir>**` → Save current `dir` to stack & go to `<dir>`.
- **`popd`** → Return to last `dir` from stack.
- **`Use`** → Quick navigation between directories.

### ls (List)

- Shows contents of a directory (files and subdirectories)
- Similar to Windows `dir` command
- **Useful flags:**
    - `ls -l` - long listing (shows permissions, owner, size, modification date)
    - `ls -a` - shows hidden files
    - `ls -la` - combines both (shows hidden files in long format)
    - `tree` -get the files and directories in a tree manner
    - `tree -d /` -get the directories only in a tree like manner
- Can specify directory: `ls /etc`

## Getting Help

### Three Ways to Get Help:

1. **-help flag**
    - `aircrack-ng --help`
    - Convention: double dash (--) for word options
2. **h or -? flags**
    - `nmap -h`
    - Convention: single dash (-) for single-letter options
    - Not all applications support all three options
3. **man (Manual) pages**
    - `man aircrack-ng`
    - Most detailed information
    - Navigate with: Enter (scroll), Page Up/Down, Arrow keys
    - Exit with: `q` (quit)

## Key Concepts

- **Root user**: The all-powerful superuser/system administrator with full privileges
- **Hidden files**: Some files don't show with basic `ls` - use `ls -a` to reveal them
- **Directory structure**: Linux uses `/` as root (top level), unlike Windows drive letters
- **Flags can be combined**: Use `ls -la` instead of `ls -l -a`

# ***Linux File and Process Search Commands - Study Notes***

## Basic Search Commands

### 1. **locate**

- Easiest search command
- Searches entire filesystem for keyword occurrences
- Example: `locate aircrack-ng`
- **Limitations:**
    - Can return overwhelming results
    - Uses database updated only once daily (recently created files won't appear)
    - Shows every occurrence of the search term

### 2. **whereis**

- Finds binary files specifically
- Returns: binary location, source, and man page (if available)
- Example: `whereis aircrack-ng`
- More efficient than locate - returns only binaries and man pages, not every occurrence

### 3. **which**

- Most specific binary search
- Only searches within PATH variable directories
- Returns single binary location
- Example: `which aircrack-ng`
- Typically searches: /usr/bin, /usr/sbin, and a few others

## Advanced Search

### 4. **find** - Most Powerful Search Tool

**Basic syntax:** `find directory options expression`

**Search parameters:**

- Filename
- Date (creation/modification)
- Owner
- Group
- Permissions
- Size

**Example:** `find / -type f -name apache2`

- `/` = starting directory
- `type f` = file type (ordinary file)
- `name apache2` = filename

**Performance tip:** Start search in specific directory (e.g., `/etc`) instead of root to speed up search

**Important:** find only matches exact names unless wildcards are used

### Wildcards

- = matches any character(s), any length (e.g., `apache2.*` finds files with any extension)
- `?` = matches single character (e.g., `?at` finds hat, cat, bat but not what)
- `[]` = matches characters inside brackets (e.g., `[c,b]at` finds cat and bat)

**Wildcard example:** `find /etc -type f -name apache2.\*`

## Filtering Output

### 5. **grep** - Keyword Filter

**Use with piping:** Takes output from one command as input for another using `|`

**Example:** `ps aux | grep apache2`

- `ps aux` = lists all running processes
- `|` = pipes output to grep
- `grep apache2` = filters for "apache2" keyword

**Benefits:** Saves time by displaying only relevant output from large datasets

---

## Key Takeaways

- Use **locate** for quick general searches
- Use **whereis** for finding binaries with documentation
- Use **which** for binaries in PATH
- Use **find** for complex, specific searches with multiple criteria
- Use **grep** with piping to filter command output
- Wildcards make searches more flexible when exact names are unknown

# ***Linux File and Directory Management Notes***

## Creating Files

### Method 1: cat (concatenate)

- **Create new file**: `cat > filename`
    - Enters interactive mode, type content, then press Ctrl-D to exit
    - Example: `cat > hackingskills`
- **Append to file**: `cat >> filename`
    - Uses double redirect (>>) to add content to end of file
    - Also uses Ctrl-D to exit
- **Overwrite file**: `cat > filename`
    - Single redirect (>) replaces all existing content
- **Display file contents**: `cat filename`
    - No redirect symbol needed to view contents

### Method 2: touch

- **Create empty file**: `touch filename`
- Originally designed to update file timestamps
- Creates file automatically if it doesn't exist
- New files have 0 size (no content)

## Creating Directories

- **Command**: `mkdir directoryname`
- Example: `mkdir newdirectory`
- Navigate to it: `cd newdirectory`

## Copying Files

- **Command**: `cp source destination`
- Creates duplicate, leaves original in place
- Example: `cp oldfile /root/newdirectory/newfile`
- Can rename during copy by adding new name to destination path
- Without rename, file retains original name

## Renaming Files/Directories

- **Command**: `mv oldname newname`
- Linux has no dedicated rename command
- mv (move) serves dual purpose: move OR rename
- Example: `mv newfile newfile2`

## Removing Files

- **Command**: `rm filename`
- Example: `rm newfile2`
- Permanently deletes the file

## Removing Directories

- **Empty directory**: `rmdir directoryname`
    - Only works on empty directories
    - Shows error if directory contains files
- **Directory with contents**: `rm -r directoryname`
    - `r` flag removes directory and all contents recursively
    - **⚠️ CAUTION**: Very dangerous—easy to accidentally delete important files
    - Using `rm -r` in home directory would delete everything

## Key Symbols

- `>` = redirect/overwrite
- `>>` = append
- `r` = recursive (for directories and contents)

## **Hard Link**

- Points directly to the **inode** (actual data) of a file.
- Multiple names for the **same file**.
- Cannot link directories.
- Cannot span across different filesystems.
- File data exists until **all hard links are deleted**.
- **Command:** `ln filename linkname`
- **Check inode:** `ls -li filename linkname` (both same inode).

---

## **Soft Link (Symbolic Link)**

- Points to the **filename/path** of another file.
- Can link **files and directories**.
- Can span **different filesystems**.
- Becomes **broken** if the original file is deleted.
- **Command:** `ln -s filename linkname`
- **Check link:** `ls -l linkname` (`linkname -> filename`).
