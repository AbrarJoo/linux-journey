## **Day 1: System Info & User Enumeration**

### **Script 1: Gather System Information**

**Objective:** Learn to use Bash for basic reconnaissance.

```bash
#!/bin/bash
echo "===== SYSTEM INFORMATION ====="
echo "Hostname: $(hostname)"
echo "OS: $(uname -o)"
echo "Kernel: $(uname -r)"
echo "CPU: $(lscpu | grep 'Model name')"
echo "Memory: $(free -h | grep Mem)"
echo "Disk Usage: $(df -h /)"
echo "Network Interfaces: $(ip -br a)"

```

**Expected Outcome:** Prints system info for recon purposes.

---

### **Script 2: List Users & Login Info**

**Objective:** Enumerate system users and potential privilege escalations.

```bash
#!/bin/bash
echo "===== USERS ====="

echo "===== SUDO USERS ====="

```

**Expected Outcome:** Lists users, login times, and sudo-enabled accounts.

## **Day 2: File & Directory Recon**

### **Script 1: Sensitive Files Finder**

**Objective:** Identify sensitive files and hidden files in home directory.

```bash
#!/bin/bash
echo "===== KEY FILES ====="
for file in /etc/passwd /etc/shadow; do
  [ -f "$file" ] && ls -l "$file"
done
echo "===== HIDDEN FILES ====="
find ~ -type f -name ".*"

```

**Expected Outcome:** Reveals important system files and hidden files.

---

### **Script 2: Directory Permissions Scanner**

**Objective:** Identify world-readable/writable files for privilege escalation.

```bash
#!/bin/bash
echo "===== WORLD-READABLE FILES ====="
find / -type f -perm -004 2>/dev/null
echo "===== WORLD-WRITABLE FILES ====="
find / -type f -perm -002 2>/dev/null

```

**Expected Outcome:** Detects files with insecure permissions.

## **Day 3: Network Scanning Basics**

### **Script 1: Local Network Scan**

**Objective:** Discover live hosts on LAN using Bash.

```bash
#!/bin/bash
network=$(ip -o -f inet addr show | awk '/scope global/ {print $4}')
IFS=/ read subnet mask <<< "$network"
echo "Scanning subnet: $subnet"
for ip in $(seq 1 254); do
  ping -c 1 -W 1 "${subnet%.*}.$ip" &>/dev/null && echo "Host ${subnet%.*}.$ip is up"
done

```

**Expected Outcome:** Lists active hosts on local network.

---

### **Script 2: Open Ports Checker**

**Objective:** Identify open TCP ports on local host.

```bash
#!/bin/bash
echo "===== OPEN PORTS ====="
for port in {20..1024}; do
  timeout 1 bash -c "echo > /dev/tcp/127.0.0.1/$port" 2>/dev/null && echo "Port $port is open"
done

```

**Expected Outcome:** Displays all open TCP ports (20–1024).

## **Day 7: Automation & Alerts**

### **Script 1: Disk Space Alert**

**Objective:** Monitor disk usage and alert if above threshold.

```bash
#!/bin/bash
USAGE=$(df / | awk 'NR==2 {print $5}' | sed 's/%//')
THRESHOLD=80
[ "$USAGE" -gt "$THRESHOLD" ] && echo "Disk usage critical: $USAGE%"

```

### **Script 2: Real-Time Log Monitoring**

**Objective:** Watch auth.log for failed login attempts and alert.

```bash
#!/bin/bash
tail -n0 -F /var/log/auth.log | while read line; do
  echo "$line" | grep "Failed password" && echo "ALERT: Failed login attempt"
done

```

## **Day 9: Web Monitoring & cURL**

### **Script 1: Website Availability Checker**

```bash
#!/bin/bash
URL="https://example.com"
status=$(curl -s -o /dev/null -w "%{http_code}" $URL)
[ "$status" -ne 200 ] && echo "Website $URL is DOWN" || echo "$URL is UP"

```

**Objective:** Learn `curl` and HTTP monitoring.

---

### **Script 2: Monitor Multiple Websites**

```bash
#!/bin/bash
sites=("https://example1.com" "https://example2.com")
for site in "${sites[@]}"; do
  status=$(curl -s -o /dev/null -w "%{http_code}" $site)
  [ "$status" -ne 200 ] && echo "$site is DOWN"
done

```

**Objective:** Automate multi-site monitoring.

## **Day 10: File Event Monitoring (inotify)**

### **Script 1: Watch Directory for Changes**

```bash
#!/bin/bash
WATCH_DIR="$HOME/test"
inotifywait -m -e create -e modify -e delete "$WATCH_DIR" |
while read dir event file; do
  echo "Event: $event on $file"
done

```

**Objective:** Learn to automate reactions to filesystem changes.

---

### **Script 2: Backup Modified Files**

```bash
#!/bin/bash
WATCH_DIR="$HOME/test"
BACKUP_DIR="$HOME/test_backup"
mkdir -p "$BACKUP_DIR"
inotifywait -m -e modify,create "$WATCH_DIR" |
while read dir event file; do
  cp "$dir$file" "$BACKUP_DIR/"
  echo "Backed up: $file"
done

```

**Objective:** Automate backups of changed files.
