## **19. Introduction to `grep`**

### Purpose

- Search text patterns in files or input streams.
- Powerful for log analysis and text filtering.

### Basic Syntax

```bash
grep [options] pattern [file...]
grep "term" file.txt
grep "pattern" *.txt
grep "pattern" file1.txt file2.txt

```

### Common Options

| Option | Description |
| --- | --- |
| `-i` | Case-insensitive |
| `-v` | Invert match |
| `-n` | Show line numbers |
| `-c` | Count matches |
| `-r` | Recursive search |
| `-l` | Show filenames only |
| `-w` | Match whole words |

### Context

```bash
grep -A 3 "error" file.txt   # 3 lines after
grep -B 2 "error" file.txt   # 2 lines before
grep -C 5 "error" file.txt   # 5 lines before & after

```

### Regular Expressions

```bash
grep "^Error" file.txt        # Start of line
grep "complete$" file.txt     # End of line
grep "c.t" file.txt           # Any char
grep "[0-9]" file.txt         # Any digit
grep -E "error|warning" file.txt  # Extended regex OR
grep -E "[0-9]{2,4}" file.txt     # 2–4 digits

```

### Practical Use

```bash
grep -q "pattern" file.txt && echo "Found"
ps aux | grep "[n]ginx"    # Filter process without matching grep

```

## **20. Introduction to `awk`**

### Purpose

- Process structured text, extract fields, perform calculations.

### Basic Syntax

```bash
awk '{print $1, $3}' file.txt
awk -F: '{print $1, $7}' /etc/passwd

```

### Built-in Variables

| Variable | Description |
| --- | --- |
| `$0` | Entire line |
| `$1..$NF` | Fields |
| `$NF` | Last field |
| `NR` | Line number |
| `NF` | Number of fields |

### BEGIN & END

```bash
awk 'BEGIN{print "Start"} {print $0} END{print "End"}' file.txt

```

### Arithmetic & Aggregation

```bash
awk '{sum+=$1} END{print sum}' file.txt
awk '{sum+=$1; count++} END{print sum/count}' file.txt
awk 'BEGIN{max=0} {if($1>max) max=$1} END{print max}' file.txt

```

### Arrays & Associative Arrays

```bash
awk '{count[$1]++} END{for(w in count) print w, count[w]}' file.txt
awk '{sum[$1]+=$2} END{for(k in sum) print k, sum[k]}' file.txt

```

### Examples

- Extract CSV columns: `awk -F',' '{print $1,$3}' data.csv`
- Sum column: `awk -F',' '{sum+=$4} END{print sum}' sales.csv`
- Filter logs: `awk '$3>1000 {print $1,$2,$3}' data.csv`

## **21. Introduction to `sed`**

### Purpose

- Stream editor for automated text transformations.

### Substitution

```bash
sed 's/old/new/' file.txt        # first occurrence
sed 's/old/new/g' file.txt       # all occurrences
sed -i 's/old/new/g' file.txt    # in-place
sed -i.bak 's/old/new/g' file.txt # backup

```

### Addressing Lines

```bash
sed '5s/old/new/' file.txt       # Line 5
sed '2,5s/old/new/' file.txt     # Lines 2–5
sed '/pattern/s/old/new/' file.txt
sed '/pattern/!s/old/new/' file.txt

```

### Delete / Insert / Append / Change

```bash
sed '5d' file.txt                # delete line 5
sed '5i\New text' file.txt       # insert before line 5
sed '5a\New text' file.txt       # append after line 5
sed '5c\Replacement line' file.txt # change line

```

### Print

```bash
sed -n '5p' file.txt             # print line 5
sed -n '/pattern/p' file.txt     # print matching lines

```

### Regular Expressions

```bash
sed 's/^/PREFIX: /' file.txt
sed 's/$/ SUFFIX/' file.txt
sed 's/\([A-Za-z]\+\) \([A-Za-z]\+\)/\2 \1/' file.txt  # swap words

```

### Practical Examples

- Config editing: `sed -i 's/^port=.*/port=8080/' config.conf`
- Log processing: `sed '/DEBUG/d' log.txt`
- Data cleaning: `sed 's/ \+/ /g' data.txt`
- CSV delimiter change: `sed 's/,/|/g' data.csv`

## **22. Debugging Bash Scripts**

### Shell Options

| Option | Description |
| --- | --- |
| `set -x` | Show commands |
| `set -e` | Exit on error |
| `set -u` | Error on undefined variables |
| `set -o pipefail` | Pipeline fails if any command fails |
| `set -euxo pipefail` | Strict mode (combine all) |

### Command-line Debugging

```bash
bash -x script.sh       # debug mode
bash -n script.sh       # syntax check only
bash -x script.sh 2>debug.log

```

### PS4 Custom Prompt

```bash
export PS4='+(${BASH_SOURCE}:${LINENO}): ${FUNCNAME[0]:+${FUNCNAME[0]}(): }'
set -x

```

### Trap Command

```bash
trap 'echo "Error on line $LINENO"' ERR
trap 'echo "Exiting..."' EXIT
trap 'rm -f /tmp/tempfile' EXIT

```

### Logging Functions

```bash
log() { echo "[$(date '+%F %T')] $1" | tee -a "$LOG_FILE"; }
log_debug() { echo "[DEBUG] $1" | tee -a "$LOG_FILE"; }
log_info() { echo "[INFO] $1" | tee -a "$LOG_FILE"; }
log_warn() { echo "[WARN] $1" | tee -a "$LOG_FILE"; }
log_error() { echo "[ERROR] $1" | tee -a "$LOG_FILE"; }

```

### ShellCheck

```bash
sudo apt-get install shellcheck
shellcheck script.sh

```

### Debugging Best Practices

1. Validate inputs and file existence.
2. Check command success (`if ! command; then ...`).
3. Quote variables: `rm "$file"`.
4. Use functions for clarity.

### Full Example

```bash
#!/bin/bash
set -euo pipefail
DEBUG=${DEBUG:-0}; [ "$DEBUG" -eq 1 ] && set -x
export PS4='+(${BASH_SOURCE}:${LINENO}): '

LOG_FILE="/tmp/script_debug.log"
log() { echo "[$(date '+%F %T')] $1" | tee -a "$LOG_FILE"; }

error_exit() { log "ERROR: $1"; exit 1; }
trap 'error_exit "Script failed on line $LINENO"' ERR

log "Script started"
# main logic here
log "Script completed"

```

Run with debugging:

```bash
DEBUG=1 bash script.sh input.txt

```
